# 🎮 Tic-Tac-Toe Game

A simple and interactive **Tic-Tac-Toe** game built using **HTML, CSS, and JavaScript**.

## 📌 About the Project

This project is a browser-based two-player Tic-Tac-Toe game.

Two players take turns placing **X** and **O** on a 3×3 board. The first player to get three of their symbols in a row, column, or diagonal wins the game.

The game also keeps track of the score between the two players.

## ✨ Features

* 🎮 Two-player gameplay
* ❌ X and ⭕ O symbols
* 🏆 Automatic winner detection
* 🤝 Draw detection
* 📊 Score tracking
* 🔄 New Game button
* ✨ Interactive and responsive interface
* 🌐 Runs directly in a web browser
* 💻 No additional software or libraries required

## 🛠️ Technologies Used

* **HTML** – Structure of the game
* **CSS** – Styling, layout, animations, and design
* **JavaScript** – Game logic, turns, winner detection, and score tracking

## ▶️ How to Run

### Method 1: Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The game will open in your default web browser.
5. Start playing!

### Method 2: Play Online

If GitHub Pages is enabled for this repository:

1. Open the GitHub Pages link.
2. The Tic-Tac-Toe game will load in your browser.
3. No installation is required.

## 🎯 How to Play

1. Player **X** starts the game.
2. Click on any empty square.
3. Player **O** takes the next turn.
4. Continue taking turns.
5. Get three of your symbols in a row, column, or diagonal to win.
6. If all nine spaces are filled without a winner, the game ends in a draw.
7. Click **New Game** to start another round.

## 🏆 Winning Conditions

A player wins by getting three matching symbols in any of these ways:

```text
X | X | X
---------
O | O | 
---------
  |   |
```

or

```text
X | O | 
---------
X | O |
---------
X |   |
```

or diagonally:

```text
X | O |
---------
O | X |
---------
  |   | X
```

## 🔄 New Game

Click the **New Game** button to clear the board and start a new round.

The player scores are maintained so you can keep track of multiple rounds.
